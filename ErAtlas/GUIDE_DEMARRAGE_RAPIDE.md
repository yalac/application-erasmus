# 🚀 Guide de démarrage rapide - ErAtlas

*Pour une documentation complète, consultez le fichier `DOCUMENTATION_UTILISATEUR.md`*

---

## 📋 En moins de 5 minutes

### 1️⃣ Lancer l'application
Double-cliquez sur `ErAtlas.exe` (dossier `bin`)

### 2️⃣ Se connecter
```
Login : [votre identifiant]
Mot de passe : [votre mot de passe]
Cliquez sur "Connexion"
```

### 3️⃣ Naviguer dans l'app
Une fois connecté, vous verrez un menu en haut avec les options disponibles :
- **Accueil** : tableau de bord
- **Mes trajets** : voir vos trajets
- **Paramètres** : gérer votre profil
- *(+ options supplémentaires si vous êtes gestionnaire)*

---

## 🎯 Tâches courantes

### Voir mes trajets
1. Cliquez sur **Mes trajets** dans le menu
2. Cliquez sur un trajet pour voir les détails (départ, arrivée, horaires, transport)

### Voir les détails d'un trajet
1. Cliquez sur le trajet dans la liste
2. Vous verrez :
   - 📍 Lieux (départ/arrivée)
   - 🕐 Dates et heures
   - 🚌 Type de transport et capacité
   - 📝 Description

### Me déconnecter
1. Cliquez sur **Paramètres** dans le menu
2. Cliquez sur **Déconnexion**

---

## 👑 Je suis gestionnaire, comment...

### Créer un trajet ?
1. **Gestion des trajets** → **➕ Ajouter un trajet**
2. Remplissez : dates, heures, lieux, transport, statut
3. Cliquez **Créer**

### Modifier un trajet ?
1. **Gestion des trajets**
2. Sélectionnez le trajet → **✏️ Modifier**
3. Changez les infos → **Enregistrer**

### Supprimer un trajet ?
1. **Gestion des trajets**
2. Sélectionnez le trajet → **🗑️ Supprimer**
3. Confirmez

### Créer un utilisateur ?
1. **Gestion des utilisateurs** → **➕ Ajouter un utilisateur**
2. Remplissez les champs obligatoires :
   - Nom, Prénom, Email, Login, Mot de passe
3. Cliquez **Créer**

### Modifier un utilisateur ?
1. **Gestion des utilisateurs**
2. Sélectionnez l'utilisateur → **✏️ Modifier**
3. Changez les infos → **Enregistrer**

### Supprimer un utilisateur ?
1. **Gestion des utilisateurs**
2. Sélectionnez l'utilisateur → **🗑️ Supprimer**
3. Confirmez

## 🆘 Aide rapide

| Problème | Solution |
|----------|----------|
| **Impossible de se connecter** | Vérifiez login/mot de passe. Vérifiez que SQL Server est démarré |
| **Aucun trajet ne s'affiche** | Actualisez la page (F5). Déconnectez/reconnectez-vous |
| **Erreur en créant un trajet** | Vérifiez tous les champs obligatoires. Vérifiez les formats (dates, heures) |
| **Autre problème** | Relancez l'app. Redémarrez votre ordinateur. Contactez l'administrateur |
